About DevPulse

Decoupled developer telemetry & cloud observability starter

The Vision

DevPulse offers an ultra-lightweight, self-hosted alternative to heavy enterprise APM suites. It delivers immediate local observability for backend services, containers, and development environments with zero cloud vendor lock-in.

Privacy & Compliance

Strictly anonymous, local-only machine counters. Absolutely zero Personally Identifiable Information (PII) collection, zero external tracking pixels, and zero AI/ML training infrastructure.

Production Architecture

Asynchronous FastAPI ASGI runtime exposing standard Prometheus exposition metrics (/metrics), paired with a reactive React 18 TypeScript SPA and automated GitHub Actions CI/CD.

About DevPulse

Decoupled Developer Telemetry & System Observability

The Project Idea

Conceived as a vital signs monitor for developers, DevPulse provides continuous observability from the very first line of code. Just like a hospital telemetry monitor records vital signs without interfering with the patient, DevPulse tracks system hardware health (CPU, RAM, disk, uptime) and lifecycle events (tests, builds, deployments) with zero background daemons, zero external cloud dependencies, and zero privacy risks.

⚡ Zero-Overhead Metrics

Samples system telemetry (CPU, RAM, disk, uptime) with lightweight OS counters and exports via Prometheus RFC 0.0.4 format.

🛡️ Zero Personal Data

Operates strictly with anonymous machine counters. No personal data, tracking cookies, or external telemetry exfiltration.

🔧 Decoupled Architecture

Modular Python FastAPI backend enforcing strict Pydantic v2 schemas paired with a typed React 18 TypeScript SPA.

☁️ Cloud-Ready DevOps

Equipped with Docker Compose, Kubernetes manifests with health probes, and Terraform AWS ECS/CloudWatch configurations.
